# Contributing to Lore.io

Thanks for helping build Lore.io.

## Before contributing

- Keep Lore.io focused on Minecraft myths, lore, universes, characters, and dynamic events.
- Keep documented real-world facts separate from fictional or fan-made lore.
- Avoid adding unnecessary complexity when a simpler system works.
- Do not commit secrets, API keys, or private credentials.

## Project areas

- `docs/` — project and gameplay documentation
- `data/` — structured myth and universe data
- `src/` — Minecraft mod source code
- `assets/` — Minecraft assets
- `config/` — configuration and examples

## Pull requests

Explain what changed, why it belongs in Lore.io, and any gameplay impact. Keep changes focused and avoid unrelated edits.
